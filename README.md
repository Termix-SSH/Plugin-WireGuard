## Overview

WireGuard installs and manages WireGuard on your hosts over SSH. Each host gets its own tab for interfaces, clients, the config and the logs.

Read the [docs](https://docs.termix.site/plugins/wireguard) to set it up and use it.

<br />

## Features

- Install WireGuard and start, stop or restart interfaces from Termix
- Create server interfaces with NAT, IP forwarding and the firewall port set up for you
- Add clients with generated keys, a free address, a config file and a QR code
- Turn clients on or off, give them new keys and remove them
- Live handshake and traffic for every client
- Edit the raw config with a check before it is saved, and read the logs
- Interfaces made by the Tunnels plugin are left alone
- A WireGuard card in Host Metrics
- Start, stop and restart interfaces through Termix actions, with down interfaces as a status tile
